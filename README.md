# Flip-n-Grill
Smash burgers, Two Omars, One Grill. A comic / anime-style website for Flip & Grill, the smash burger stall at IBA Karachi.

The site has two jobs:

Tell IBA students about the stall: what's on the menu, where to find it, and why they need to go.
Get catering bookings from events in Karachi (bazaars, weddings, mehndis, corporate lunches, uni events, parties) via WhatsApp, email or Instagram.
Instagram: @flipngrill_
